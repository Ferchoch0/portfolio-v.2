Bienvenido al repositorio de mi portafolio personal interactivo. Este proyecto está diseñado para ofrecer una experiencia visual inmersiva, moderna y premium que muestra mi trayectoria profesional, habilidades técnicas, y proyectos seleccionados.

Como fundador y Tech Lead de **Utterly** (equipo de desarrollo de software freelance), enfoco mi trabajo tanto en el criterio técnico como en la visión de negocio, gestionando desde la arquitectura frontend y backend hasta mi propia infraestructura de servidores.

---

## ✨ Características Principales

*   **Experiencia Inmersiva y Animaciones:** Animaciones avanzadas en scroll y micro-interacciones utilizando **GSAP** (GreenSock Animation Platform) + **ScrollTrigger** y **Framer Motion**.
*   **Scroll Ultra Suave:** Integración con **Lenis Scroll** para una navegación fluida y natural a lo largo de toda la aplicación.
*   **Internacionalización (i18n):** Traducido completamente a tres idiomas (**Español**, **Inglés** e **Italiano**), gestionado dinámicamente mediante `react-i18next`.
*   **Formulario de Contacto Inteligente:** Formulario interactivo con flujos especializados para **Reclutadores** (información corporativa y vacantes) y **Clientes** (especificaciones de proyectos), integrado con **EmailJS**.
*   **Diseño Exclusivo y Adaptativo:** Estilo moderno (Glassmorphism, gradientes armoniosos y modo oscuro elegante) optimizado tanto para dispositivos móviles como pantallas de alta resolución.
*   **Infraestructura de Servidores:** Configurado y optimizado para ser desplegado en entornos autogestionados mediante **Nginx** y herramientas de túneles como **Ngrok** para pruebas en tiempo real.

## 📁 Estructura del Proyecto

El proyecto sigue una estructura limpia y modular orientada a componentes en React:

```text
portfolio-v.2/
├── public/                 # Recursos públicos (imágenes de proyectos, logotipos, etc.)
└── src/
    ├── assets/             # Assets estáticos y recursos multimedia
    ├── components/         # Componentes globales reutilizables (Navbar, Footer, Cursor personalizado, etc.)
    ├── data/               # Datos estáticos (ej: listado de proyectos en projectsData.js)
    ├── hooks/              # Hooks personalizados para lógica interactiva
    ├── locales/            # Traducciones del sitio (en.json, es.json, it.json)
    ├── pages/              # Páginas principales (Inicio, Contacto, etc.)
    ├── routes/             # Enrutamiento de la aplicación (AppRoutes.jsx)
    ├── sections/           # Secciones modulares de la landing page (Hero, AboutMe, Skills, Services, Works)
    ├── App.jsx             # Componente raíz del árbol de React
    ├── i18n.js             # Configuración de react-i18next
    ├── index.css           # Estilos CSS globales y variables de diseño
    └── main.jsx            # Punto de entrada de la aplicación
```
